## Agent Use

- Infer missing fields when the codebase makes intent clear.
- Ask one concise clarification only when safe execution depends on an unknown business or contract decision.
- Convert broad requests into the smallest concrete boundary before searching.
- Keep the user's original goal visible through Plan, Implement Plan, Report, and Update skill files.
